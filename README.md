# Student Management System

An interactive web-based Student Management System developed using **HTML, CSS, and JavaScript**. The project provides a dashboard for managing student and academic information through a responsive and user-friendly interface.

The application runs entirely in the browser and uses **Local Storage** for data persistence.

## Features

### Student Management
- Add new students
- View student profiles
- Edit student information
- Delete student records
- Search students by name, ID, or email
- Filter students by semester and status
- Track GPA and active/inactive status

### Results Management
- Add and manage student results
- Calculate percentages and grades
- Calculate GPA from student results
- Search and filter results
- Display class average, highest score, and failing results

### Attendance Management
- Mark students as Present, Absent, or Late
- Maintain attendance records
- Calculate overall attendance rate
- Track daily attendance statistics

### Course Management
- Add, edit, and delete courses
- Store course codes, teachers, semesters, schedules, rooms, and enrollment information
- Search and filter courses

### Examination Management
- Schedule examinations
- Edit and delete examination records
- Track upcoming, current, and completed exams
- Store exam date, time, room, duration, semester, and marks

### Reports
- Student summary report
- Results report
- Attendance report
- Courses report
- Examinations report
- Top performers report
- At-risk students report
- Export reports to Excel (.xlsx)
- Print dashboard summary

### Customization and Data Management
- Light and dark mode
- Multiple accent colour themes
- Compact table mode
- Custom school/department information
- Browser Local Storage for data persistence
- Export complete application data as a JSON backup
- Restore data from a JSON backup
- Clear stored application data

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- Font Awesome
- SheetJS (XLSX) for Excel export
- Responsive Web Design

## Project Structure

The project is implemented in a single `index.html` file containing the HTML structure, CSS styling, and JavaScript functionality.

## Data Storage

This version does not use a backend database. Student, result, attendance, course, examination, and application-setting data are stored locally in the user's browser using the Web Storage API.

## Purpose

This project was developed to practice front-end web development and demonstrate how HTML, CSS, and JavaScript can be combined to create an interactive academic management interface.

It demonstrates concepts including DOM manipulation, event handling, form processing, data filtering, browser storage, responsive design, data export, and dynamic user-interface updates.
